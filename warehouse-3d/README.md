# Склад 3D

Веб-приложение для построения 3D-карты складов: форма помещений → зоны размещения и их высота →
стеллажи, ярусы и ячейки (Д × Ш × В, Г) → подключение к учётной системе → заполнение.

```bash
cd warehouse-3d
npm install
npm run dev      # http://localhost:5173
npm test         # юнит-тесты
npm run build    # сборка в dist/
```
