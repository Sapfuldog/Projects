# Склад 3D

Веб-приложение для 3D-карты складов и складского учёта: от формы помещений до ячеек с размерами
**Д × Ш × В** и грузоподъёмностью **Г**, с подключением к учётной системе и отображением заполнения.
Можно вести сколько угодно объектов (складов).

## Возможности

**Главная** — KPI (общий остаток, занятость, поступления и отгрузки за 7 дней с динамикой), остатки
по складу, 3D-карта с выносками загрузки зон и доков, лента последних событий и документы в работе.

**Склад → Конструктор склада** (вкладки-палитры):

| Вкладка | Что делается |
|---|---|
| Здания | форма помещений (прямоугольное, Г-, П-, Т-образное или контур по углам), высота, отметка пола; стены, перегородки, двери, ворота, колонны |
| Зоны | зоны размещения нужного типа и **высота зоны размещения** (ограничивает стеллажи) |
| Стеллажи | паллетные/полочные стеллажи, генератор рядов, секции, ярусы (В, число ячеек, Г) |
| Ячейки | шаблон адреса, фасад стеллажа, Д × Ш × В × Г каждой ячейки, блокировка, выгрузка CSV |
| Оборудование | погрузочные рампы, конвейеры, погрузчики (ездят по проходу), фуры |
| Другое | рабочие зоны, офис, санузел |

План и 3D работают вместе: перетаскивание вершин, стеллажей и объектов, привязка к сетке, отмена/повтор
(Ctrl+Z / Ctrl+Shift+Z). Объект из палитры ставится щелчком на 3D или на плане.

**Остатки** — каталог товаров (вес и объём единицы, минимум, норма, цена, штрихкод), фильтры
«Все / В наличии / Низкий остаток / Нет в наличии», ячейки хранения и история движения, импорт/экспорт CSV.

**Поставки и Заказы** — документы прихода и отгрузки. Приложение само подбирает ячейки:
при приёмке — по объёму и грузоподъёмности (крупное на нижние ярусы, мелкое в небольшие ячейки),
при отгрузке — сначала почти пустые ячейки. Маршрут подсвечивается на 3D. Перемещение и инвентаризация —
из карточки ячейки.

**Аналитика** — структура запасов по категориям, динамика остатков, поступления и отгрузки по дням,
загрузка зон, оборот товаров и ABC-анализ.

**Уведомления** — низкий остаток, перегруз ячеек (вес > Г), ошибки подключения, документы в работе.

**Настройки → Подключение** — источник заполнения:

- _Внутренний учёт_ — по остаткам из разделов «Поставки», «Заказы», «Остатки»;
- _REST API_ — опрос WMS / 1С / БД (JSON или CSV), сопоставление полей, выгрузка структуры ячеек POST-запросом;
- _WebSocket_ — изменения в реальном времени;
- _Файл_ — CSV из Excel (разделитель «;» или «,») или JSON;
- _Демо-симулятор_.

Формат данных о заполнении:

```json
{
  "items": [
    { "address": "A-01-01-01", "fill": 0.8, "weight": 640, "sku": "12345", "name": "Вода 0,5л" },
    { "address": "A-01-02-03", "qty": 12, "capacity": 40 }
  ]
}
```

Адрес ячейки собирается по шаблону `{room} {zone} {rack} {section} {tier} {cell}`
(по умолчанию `{rack}-{section}-{tier}-{cell}` → `A-01-02-03`) и должен совпадать с адресом в учётной системе.

## Запуск

```bash
cd warehouse-3d
npm install
npm run dev          # http://localhost:5173
npm test             # юнит-тесты (геометрия, ячейки, размещение, журнал, аналитика)
npm run build        # сборка в dist/
npm run build:single # всё приложение одним HTML-файлом в dist-single/
npm run mock-wms     # тестовый WMS для проверки REST-подключения (http://localhost:8787)
```

Проверка REST: запустите `npm run mock-wms`, в «Настройки → Подключение → REST API» укажите
`http://localhost:8787/api/locations` как адрес выгрузки структуры и нажмите «Отправить структуру»,
затем URL `http://localhost:8787/api/stock`, путь к массиву `items` → «Загрузить сейчас».

Данные хранятся в браузере (IndexedDB). Для переноса — «Настройки → Объекты и данные → Выгрузить».

## Устройство

- `src/types.ts` — модель: склад → помещения → зоны → стеллажи → ярусы → ячейки; оборудование; товары, остатки, документы, журнал.
- `src/lib/rack.ts` — геометрия стеллажа и расчёт ячеек (Д = секция / число ячеек, Ш = глубина, В = ярус, Г).
- `src/lib/inventory.ts` — адресное хранение: подбор ячеек, отбор, проведение операций, заполнение по остаткам.
- `src/lib/analytics.ts`, `src/lib/alerts.ts` — KPI, ряды по дням, ABC, уведомления.
- `src/lib/connectors.ts` — REST / WebSocket / файл / демо.
- `src/components/scene` — 3D (three.js, react-three-fiber): тысячи ячеек одним instanced-мешем, оборудование, выноски.
- `src/components/plan` — 2D-редактор плана (SVG).
- `src/pages` — разделы приложения.
