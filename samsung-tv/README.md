# Пульт для Samsung Smart TV (Tizen)

Скрипт `tv.py` управляет телевизором Samsung на Tizen (модели 2016+) по локальной сети,
через тот же WebSocket API, что и приложение SmartThings: кнопки пульта, громкость,
запуск приложений, браузер, ввод текста, включение по Wake-on-LAN.

**Компьютер должен быть подключён к тому же роутеру (Wi-Fi), что и телевизор.**

## Установка

1. Python 3.10+ (Windows: https://www.python.org/downloads/, при установке отметить «Add Python to PATH»).
2. В папке `samsung-tv`:

   ```
   pip install -r requirements.txt
   ```

## Настройка телевизора (один раз)

- **Разрешить подключение внешних устройств:**
  Настройки → Общие → Диспетчер внешних устройств → Диспетчер подключения устройств →
  «Уведомление о доступе» включено.
- **Для включения командой `on`:** Настройки → Общие → Сеть → Экспертные настройки →
  «Включение с мобильного устройства» (Power On with Mobile) — включить.

## Подключение

```
python tv.py find          # найдёт ТВ в сети и запомнит его IP и MAC
python tv.py connect       # на экране ТВ нажмите «Разрешить»
```

Если `find` не нашёл телевизор, посмотрите IP на самом ТВ
(Настройки → Общие → Сеть → Состояние сети → Настройки IP) и укажите его явно:

```
python tv.py connect 192.168.1.50
```

После «Разрешить» токен сохраняется в `tv.json`, и дальше команды работают без подтверждения.

## Команды

| Команда | Что делает |
|---|---|
| `python tv.py info` | модель, IP, MAC, включён ли ТВ |
| `python tv.py on` / `off` | включить (Wake-on-LAN) / выключить |
| `python tv.py vol up 5` | громкость +5 (`down`, `mute`) |
| `python tv.py key KEY_HOME` | любая кнопка пульта (`KEY_RETURN`, `KEY_SOURCE`, `KEY_CHUP`, …) |
| `python tv.py app youtube` | запустить приложение: `youtube`, `netflix`, `prime`, `spotify` или appId |
| `python tv.py apps` | список установленных приложений с appId (поддерживают не все ТВ) |
| `python tv.py url https://ya.ru` | открыть сайт во встроенном браузере |
| `python tv.py text "фильм"` | ввести текст в открытое на ТВ поле ввода |
| `python tv.py remote` | интерактивный пульт: `up`, `down`, `ok`, `back`, `home`, `+`, `-`, цифры… (`q` — выход) |

## Если не работает

- **«Телевизор отклонил подключение»** — в Диспетчере подключения устройств найдите
  «Python Remote» и выберите «Разрешить», либо удалите его и снова выполните `connect`.
- **«Не удалось подключиться»** — ТВ выключен или компьютер в другой сети
  (например, гостевой Wi-Fi). Проверьте `python tv.py info`.
- **Старые модели (2014–2015, Orsay)** не поддерживают этот API. Для моделей 2016 года без
  токена попробуйте `python tv.py --port 8001 connect`.
- **`on` не включает** — проверьте «Включение с мобильного устройства»; если ТВ подключён
  кабелем, укажите в `tv.json` MAC проводного адаптера (Состояние сети → Настройки IP).
